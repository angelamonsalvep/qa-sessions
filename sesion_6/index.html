JavaScript

Pruebas Unitarias en JS: Jest

Jest es la librería de testing más popular en el ecosistema JS. Creada por Facebook (Meta).

Detalles de la Librería

Licencia: Gratuita (MIT).

Compatibilidad: Proyectos Node.js, Vanilla JS. (Soporta React de forma nativa).

Requisitos: Node.js instalado (npm install --save-dev jest).

Uso: Provee un entorno completo: Test Runner, Assertion Library y Mocking en un solo paquete.

// math.test.js
const { sum } = require('./math');

test('suma 1 + 2 para dar 3', () => {
  expect(sum(1, 2)).toBe(3);
});

// Ejecución: npx jest
JavaScript

Pruebas End-to-End (E2E): Cypress

Cypress es un framework de pruebas E2E moderno diseñado para la web actual.

Detalles de la Librería

Licencia: Gratuita (Open Source), con Dashboard pago opcional.

Compatibilidad: Cualquier framework web moderno (React, Angular, Vue).

Requisitos: Node.js (npm install cypress --save-dev).

Uso: Se ejecuta en el mismo ciclo de vida que la aplicación. No usa Selenium bajo el capó.

// login.cy.js
describe('Flujo de Login', () => {
  it('Debe iniciar sesión exitosamente', () => {
    cy.visit('/login');
    cy.get('input[name=user]').type('admin');
    cy.get('input[name=pass]').type('1234');
    cy.get('button[type=submit]').click();
    cy.url().should('include', '/dashboard');
  });
});

    expect(service).toBeTruthy();

TypeScript (React/Next.js)

Pruebas Componentes: Vitest + React Testing Lib

La combinación moderna para React y Next.js.

Detalles de la Librería

Licencia: Gratuitas (MIT).

Compatibilidad: React, Vue, Svelte. Ideal para empaquetadores como Vite o Turbopack.

Requisitos: Node.js. npm i -D vitest @testing-library/react

Uso: Vitest reemplaza a Jest por ser más rápido (basado en Vite). RTL prueba componentes simulando la interacción del usuario.

// Button.test.tsx
import { render, screen, fireEvent } from '@testing-library/react';
import { expect, test, vi } from 'vitest';
import Button from './Button';

test('dispara evento al hacer click', () => {
  const handleClick = vi.fn();
  render(<Button onClick={handleClick}>Click Me</Button>);
  
  fireEvent.click(screen.getByText(/click me/i));
  expect(handleClick).toHaveBeenCalledTimes(1);
});
TypeScript (Cualquier FW)

Pruebas E2E: Playwright

El estándar emergente de Microsoft para pruebas E2E robustas.

Detalles de la Librería

Licencia: Gratuita (Apache 2.0).

Compatibilidad: Funciona con Angular, React, Next, Vue, etc.

Requisitos: Node.js (npm init playwright@latest).

Uso: Controla navegadores Chromium, WebKit y Firefox. Excelente soporte nativo para TypeScript. Soporta múltiples pestañas e iframes fácilmente.

// app.spec.ts
import { test, expect } from '@playwright/test';

test('verifica el título de Next.js', async ({ page }) => {
  await page.goto('http://localhost:3000');
  
  // Aserción E2E automática de Playwright
  await expect(page).toHaveTitle(/Next.js/);
  
  const getStarted = page.locator('text=Get Started');
  await expect(getStarted).toBeVisible();
});
Java (Spring Boot)

Pruebas Unitarias: JUnit 5 + Mockito

El estándar absoluto para desarrollo backend en Java.

Detalles de la Librería

Licencia: Gratuita (EPL 2.0 y MIT).

Compatibilidad: Cualquier proyecto Java, integración nativa con Spring Boot (spring-boot-starter-test).

Requisitos: JDK, Maven o Gradle.

Uso: JUnit 5 maneja la ejecución de la prueba. Mockito permite "simular" (mock) dependencias externas como bases de datos para aislar la prueba.

// ServicioTest.java
import org.junit.jupiter.api.Test;
import org.mockito.Mockito;
import static org.junit.jupiter.api.Assertions.assertEquals;

class CalculadoraServiceTest {
    
    @Test
    void pruebaDescuento() {
        // Arrange
        Repositorio mockRepo = Mockito.mock(Repositorio.class);
        Mockito.when(mockRepo.getTasa()).thenReturn(10);
        
        Servicio srv = new Servicio(mockRepo);
        
        // Act
        int total = srv.calcular(100);
        
        // Assert
        assertEquals(90, total);
    }
}
Java (Spring Boot)

Pruebas de Integración: SpringBootTest + REST Assured

Pruebas que levantan el contexto de Spring para validar endpoints.

Detalles de la Librería

Licencia: Gratuita (Apache 2.0).

Compatibilidad: Proyectos Spring Boot.

Requisitos: Maven/Gradle con dependencias spring-boot-starter-test y rest-assured.

Uso: Levanta el servidor Tomcat embebido. REST Assured provee un lenguaje BDD (Given/When/Then) para hacer peticiones HTTP a tu propia API.

// ApiTest.java
@SpringBootTest(webEnvironment = WebEnvironment.RANDOM_PORT)
class UserControllerIntegrationTest {

    @LocalServerPort
    private int port;

    @Test
    void debeRetornarUsuario() {
        RestAssured.given()
            .port(port)
        .when()
            .get("/api/users/1")
        .then()
            .statusCode(200)
            .body("name", equalTo("Angela"));
    }
}
Python (FastAPI / Django)

Pruebas Unitarias e Integración: Pytest

El estándar de facto para testing en todo Python.

Detalles de la Librería

Licencia: Gratuita (MIT).

Compatibilidad: Cualquier framework Python (FastAPI, Django, Flask, Data Science).

Requisitos: Python 3+ (pip install pytest).

Uso: No requiere heredar de clases raras. Usa el assert nativo de Python. Sus "Fixtures" son la mejor forma de inyectar dependencias y mocks.

# test_api.py
from fastapi.testclient import TestClient
from myapp.main import app

# FastAPI incluye un TestClient excelente
client = TestClient(app)

def test_leer_item():
    response = client.get("/items/42")
    
    # Aserciones simples y legibles con pytest
    assert response.status_code == 200
    assert response.json() == {"item_id": 42}
